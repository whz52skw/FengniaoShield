# FengniaoShield（蜂鸟盾）—— 蜂鸟骑士增强

> **LSPosed 版**（本仓库，源码 + 现成 APK）与 **整合版**（免 root，开发中，即将发布）。

## LSPosed 版 —— 下载与安装（一步步来）

**第一步：下载**
在本仓库右侧 **Releases** 里，下载最新的 `FNHook-LSPosed模块.apk`。

**第二步：装到手机**
把 apk 传到手机 → 点击安装（提示"未知来源"→ 允许）。

**第三步：在 LSPosed 里打开它**
1. 打开你手机的 LSPosed（万象设置类 App）
2. 模块 → 勾选「蜂鸟盾」
3. 作用域 → 勾选「蜂鸟骑士」（me.ele.hbdteam）
4. 重启「蜂鸟骑士」

**第四步：完事**
正常跑单即可，无需任何配置。

## 功能明细（LSPosed 版）

- 超速 / 路口超速：判定链与上报接口拦截
- 逆行：判定拦截
- 闯红灯：红绿灯判定全链拦截
- 分心驾驶（骑行使用手机）：判定/上报拦截
- 未戴头盔：采集/识别/上传全链拦截
- 违规语音播报静音
- 定位增强：GPS 判定放行（配合定位工具不被识别为异常）、无视距离
- 更新屏蔽：锁定 10.11.1，不弹强制升级
- 自动日志：崩溃/异常/每 60 秒自检，全自动记录，无需设置

## 😵 出问题了怎么办？（不懂技术也能上报）

模块会把所有问题自动写进日志文件，**你只需要把它拷贝出来**：

1. 手机文件管理 → 找到目录：
   \`Android/data/me.ele.hbdteam/files/fnhook2_logs/\`
   （部分手机系统文件管理进不去，可以用任意"文件浏览器"类 App 进）
2. 找到**昨天或今天日期**的 `.log` 文件（例如 `fn2_2025-11-25.log`）
3. 把文件发到本仓库 **Issues**（新建问题时上传附件），并写明：
   - 出了什么问题（什么时间、什么现象）
   - 你的手机品牌 + 系统版本
   - 蜂鸟版本号

> 即使你不懂里面的内容也没关系，把文件传上来即可，维护者能看懂。

## 构建（仅开发者需要）

需 JDK 17 + Android SDK 34 + Gradle 8.7。

\`\`\`bash
gradlew.bat assembleDebug   # Windows
./gradlew assembleDebug    # Linux/macOS
\`\`\`
产物：\`app/build/outputs/apk/debug/app-debug.apk\`

仓库结构：\`app/src/main/kotlin/com/fnhook2/\` 下按功能分层（详见源码注释）。

## 日志关键词速查（开发者/排查）

| 关键词 | 含义 |
|---|---|
| \`[生效]\` | 某层屏蔽正在生效（累计次数） |
| \`[自检]\` | 每 60 秒心跳，看模块是否活着 |
| \`[自检-零命中]\` | 已挂载但全程没触发的层（功能无效排查） |
| \`[崩溃]\` | 崩溃完整堆栈 |
| \`[自杀]\` | App 自杀点记录 |
